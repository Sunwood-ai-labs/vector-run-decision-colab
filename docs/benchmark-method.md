# VECTOR RUNの測り方

Decision 2.0の7モデルに、同じコース状態、質問、4つの行動候補を渡します。重みの追加学習や反射ルールによる補助は行いません。モデルが選んだ行動だけをゲームへ適用します。

## ゲームの時計

物理は60フレーム／秒、判断の機会は8フレームごとです。推論中も物理を進めます。未完了の要求がある判断機会はスキップし、要求を積み上げません。回答は、受け取った後の物理フレームで1回だけ適用します。遅い回答は、質問時点から状況が変わっていても補正しません。

計測プログラムの処理が遅れた場合も、経過した実時間に応じて物理を追いつかせます。回答までゲームを停止する計測と、リアルタイム計測は別の条件です。今回の主結果と比較動画はリアルタイム条件を使用します。

## 比較する条件

| 項目 | 条件 |
| --- | --- |
| 行動 | hold / jump / slide / strike |
| 主測定 | action、commit、dangerの3問、シード1・2・3 |
| 多問測定 | 同じ3問と61問の真偽プローブ、シード1 |
| 対照 | 明示したルールで動く走者、holdのみの走者 |
| 動画 | 共通シード1、7モデルと2対照の3×3、等速 |

各モデルのGPU、重みのrevision、dtype、量子化、ライブラリ版、ゲームcommitを結果へ記録します。GPUメモリが足りず別GPUや量子化を使った場合は、同じ条件の順位にまとめません。3問と64問の結果も分けます。

## 結果の意味

クリア率、進んだ距離、被弾数に、判断の遅れも反映されます。行動一致率は質問時点の明示ルールへの追従を測ります。多数を占めるholdだけでも一致率が上がるため、クリア率や各行動の内訳と併読してください。

推論の遅延とHTTP要求の遅延、初回とウォームアップ後を分けます。モデルカードの遅延は別環境での公開元の測定であり、今回の実測値には流用しません。

このゲームは専用の小さなポリシー追従課題です。汎用の決定能力、JevArena、Decision Index、未知のゲームでの強さを示すものではありません。

## 映像と検証

モデルをGPUへ順にロードして測った場合、3×3動画は保存した実測フレームと行動の等速再生をキャプチャします。画面に「実測trace再生」と表示し、9走者が同時にモデル推論した映像とは扱いません。再生中に物理時間を止めたり、遅いモデルだけ速度を変えたりしません。

再生の検証は保存した行動とゲーム物理の整合性確認です。モデル推論を再実行したことにはなりません。動画はメタデータ確認、全フレームのデコード、代表フレームの目視で確認します。
